# 🍔 Food Delivery System (Java Console Project)

A simple **console-based Food Delivery System** developed in **Java**.  
This project allows customers to browse food items, place orders, and make payments. It also includes an **Admin Panel** for managing the food menu and stock.

---

## 🚀 Features

### 👤 Customer
- Register new account
- Login using User ID and Password
- Browse food items:
  - Search food items
  - Show all available food
  - Purchase items
  - Show combos
- Payment options:
  - Cash on Delivery (COD)
  - Online Payment

### 🛠️ Admin
- Login with Admin credentials
- Manage food inventory:
  - Show food items
  - Edit food name and price
  - Add new food items
  - Exit system

---


## ⚙️ Technologies Used
- Java (Core)
- OOP concepts (Encapsulation, Inheritance, Polymorphism)
- Console-based input/output
